# devops-course

Домашние задания курса по DevOps.

| № | Тема | Задание | Статус |
|---|------|---------|--------|
| 02 | [Docker: тома, сети, Compose](02-docker-compose/) | Flask/FastAPI + PostgreSQL + Redis + Nginx, именованный том, холодный бэкап, изоляция сетей, оптимизация образа в dive | основная часть выполнена |

## Структура

Каждое задание лежит в своём каталоге и самодостаточно: там свой
`compose.yaml`, `Dockerfile`, `.env.example` и отчёт.

```
<NN>-<тема>/
├── README.md     как запустить
├── REPORT.md     отчёт по заданию: команды, вывод, выводы
└── ...           исходники и конфигурация
```

Команды выполняются из каталога задания:

```bash
cd 02-docker-compose
cp .env.example .env
docker compose up -d --build --wait
```

## Общее

Рабочие `.env` в репозиторий не попадают — в каждом задании есть `.env.example`
с примерными значениями. Корневой `.gitignore` действует рекурсивно на все
каталоги заданий.
